# vaultspec

Vault config/spec key checks for twelve-factor services.

**Site:** https://theworker02.github.io/vaultspec/

## Install / run

```bash
git clone https://github.com/theworker02/vaultspec.git
cd vaultspec
node src/cli.js
node --test
```
